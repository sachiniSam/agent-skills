Asgardeo CLI is a command-line interface tool designed to help you manage your Asgardeo or Identity Server organization efficiently.
With this CLI, you can perform a wide range of operations, including managing applications, users, and APIs, as well as generating and viewing documentation for the CLI itself.
The cli supports both interactive and non interactive(--no-interactive/ -n) modes

additionally you can use the TUI (asg tui) for better interactivity.

Usage:
  asg [command]

Available Commands:
  agents      Manage agents in your Asgardeo tenant
  api         Send API requests to Asgardeo
  apis        Manage your API resources
  apps        Manage your applications
  branding    Manage branding preferences
  completion  Generate the autocompletion script for the specified shell
  docs        Generate or view documentation
  groups      Manage groups in the organization
  help        Help about any command
  idps        Manage Identity Providers
  login       Log in to Asgardeo or Identity Server
  logout      Logout from the current session
  orgs        Manage organizations in Asgardeo or Identity Server
  roles       Manage roles in your Asgardeo tenant
  scopes      Manage API Resource scopes
  status      Check the authentication status of the CLI
  tui         Launch interactive dashboard
  users       Manage users in the organization

Flags:
      --format string    output format (json|yaml)
  -h, --help             help for asg
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output

Use "asg [command] --help" for more information about a command.
