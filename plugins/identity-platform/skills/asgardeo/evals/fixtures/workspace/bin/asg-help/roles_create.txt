Create a new role in your Asgardeo tenant with specified display name, users, groups, permissions, and audience.

Usage:
  asg roles create [flags]

Examples:
asg roles create --name Auditor --audience-type Application --audience-id 99e70d2c-6d8b-40d2-a716-446655440000 --permission-name internal_user_mgt_view -y
asg roles create --name ContentManager --audience-type Application --audience-id 99e70d2c-6d8b-40d2-a716-446655440000 --permission-name internal_user_mgt_view --permission-name internal_user_mgt_update -y

Flags:
      --audience-id string        ID of the audience (e.g., application ID or organization ID)
      --audience-type string      Type of the audience (Allowed: 'Application' or 'Organization')
  -h, --help                      help for create
  -n, --name string               Display name for the role (required)
  -p, --permission-name strings   List of permission names to assign to the role (-p <name1> -p <name2>)
  -y, --yes                       confirm user creation

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
