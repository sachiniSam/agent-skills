Create a new application in your organization
Supported application types: saml, oidc, spa, mobile, mcp
In interactive mode, you will be prompted for any missing values
In non-interactive mode, provide the required flags for the selected application type

Usage:
  asg apps create [flags]

Examples:
asg apps create --name "web-portal" --description "OIDC app" --type oidc --redirect-uri "http://localhost:3000/callback" -y
asg apps create --name "saml-app" --description "SAML app" --type saml --issuer "https://example.com/saml" --acs-uri "https://example.com/acs" -y
asg apps create --name "android-client" --description "Android app" --type android --redirect-uri "com.example.app:/oauth2redirect" -y
asg apps create

Flags:
      --access-token-type string   Access token format: jwt (readable by a backend checking scopes) or opaque (default)
      --acs-uri strings            ACS URI(s)
      --api-based-auth             Enable API-based (app-native) authentication, so clients can sign in over the API instead of through a browser. Required for agent authentication.
      --description string         Description of the application
  -h, --help                       help for create
      --issuer string              Issuer
  -n, --name string                Name of the application
      --redirect-uri strings       Redirect URI(s)
  -t, --type string                Type of the application
  -y, --yes                        confirm the application creation automatically

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
