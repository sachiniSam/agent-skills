Delete an existing application from your organization
In interactive mode, you can select the application to delete from the list of applications
In non-interactive mode, you need to provide the application ID

Usage:
  asg apps delete [flags]

Aliases:
  delete, del

Examples:
asg apps delete --id 7a4d5f50-cf2c-4de7-8b0f-b7f6f82c9ac4
asg apps delete --name web-portal -y
asg apps delete --query "name sw web" -y

Flags:
  -h, --help           help for delete
  -i, --id string      ID of the application you want to delete
  -n, --name string    Name prefix of the application you want to delete
  -q, --query string   Filter query to resolve the application you want to delete
  -y, --yes            confirm the deletion

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
