Delete an API Resource by providing an ID or filtering it by name prefix.

Usage:
  asg apis delete [flags]

Aliases:
  delete, del

Examples:
asg apis delete --id 77e7ee21-da02-409e-bf8a-28f3bb186814
asg apis delete --name webhook
asg apis delete --query "name sw legacy"

Flags:
  -h, --help           help for delete
  -i, --id string      ID of the API Resource to delete
  -n, --name string    Name (prefix) of the API Resource to delete
  -q, --query string   Query to filter the API Resource to delete. (Example: --query "name sw test" or --query "name co 'web'")
  -y, --yes            confirm the deletion automatically

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
