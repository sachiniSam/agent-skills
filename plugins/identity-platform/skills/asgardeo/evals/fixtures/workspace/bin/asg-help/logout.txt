Logout from the current session and clear all locally stored credentials and configurations related to the session.

Usage:
  asg logout [flags]

Aliases:
  logout, log-out

Examples:
asg logout
asg logout --no-interactive

Flags:
  -h, --help   help for logout

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
