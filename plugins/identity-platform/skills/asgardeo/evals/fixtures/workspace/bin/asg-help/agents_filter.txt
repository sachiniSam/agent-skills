Filter agents in your Asgardeo tenant based on specific SCIM2 attributes. You can specify the filter query, starting index, maximum count, and which attributes to return.

Usage:
  asg agents filter [flags]

Examples:
asg agents filter --query "name co \"support\""
asg agents filter --query "urn:scim:wso2:agent:schema.DisplayName eq \"support-assistant\"" --count 2
asg agents filter --query "description co \"orders\"" -N --format json


Flags:
      --attributes string   Comma-separated list of attributes to return for each agent
  -c, --count string        Maximum number of results to return
  -h, --help                help for filter
  -q, --query string        SCIM2 filter to select agents. Bare 'name', 'DisplayName' and 'description' are mapped to the agent schema for you; other attributes must be fully qualified
      --start string        Starting index for pagination

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
