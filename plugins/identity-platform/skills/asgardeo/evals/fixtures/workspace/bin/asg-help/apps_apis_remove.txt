Remove an API resource authorization from the application. The application can no longer request that API's scopes.

Usage:
  asg apps apis remove [flags]

Examples:
asg apps apis remove --id 7a4d5f50-cf2c-4de7-8b0f-b7f6f82c9ac4 --api-id 99e70d2c-6d8b-40d2-a716-446655440000 -y

Flags:
      --api-id string   ID of the API resource
  -h, --help            help for remove
  -i, --id string       ID of the application
  -n, --name string     Name of the application
  -q, --query string    Query to filter the application
  -y, --yes             Skip the confirmation prompt

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
