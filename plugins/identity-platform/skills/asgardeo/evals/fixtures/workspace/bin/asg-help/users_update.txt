Update an existing user's attributes by providing an ID or Name.
You can either use granular flags (-a for add, -m for replace, -r for remove) to patch the user,
You can use -r/-m/-a flags multiple times to update multiple fields. 
or use an interactive file editor (-f) to modify the full JSON representation of the user.

Interactive editing is not provided within the terminal. You can use the -f flag to export the user to a file, edit it, and then import it back.
You can use the -n flag to provide the prefix of the user name to search for the user and select the user from the list in the interactive mode.

Usage:
  asg users update [flags]

Examples:
asg users update --id 123e4567-e89b-12d3-a456-426614174000 --edit name.familyName=Smith
asg users update --name john --edit email=john.new@example.com -y
asg users update --id 123e4567-e89b-12d3-a456-426614174000 --file temp-user.json

Flags:
  -a, --add strings      path (dot separated) to add and value ('=' separated) example: name=newname
                          path.to.key=value
                          path.to.complex.json.value=@file.json
  -e, --edit strings     path (dot separated) to replace and value ('=' separated) example: name=newname
                          path.to.key=value
                          path.to.complex.json.value=@file.json
  -f, --file string      interactive: file to export the user into, edit, and re-import; non-interactive (-N): prepared JSON file to import directly
  -h, --help             help for update
  -i, --id string        User ID
  -n, --name string      name (prefix) this will be used to search for user it uses "username sw <name>" query
  -q, --query string     Query to filter the user to update. (Example: --query "username sw test" or --query "username co 'admin'")
  -r, --remove strings   path (dot seperated) to remove
  -y, --yes              confirm update automatically

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
