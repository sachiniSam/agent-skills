The groups command provides utilities to manage groups within your Asgardeo or Identity Server organization.

Use this command to list, create, view, update, and manage members and roles for groups.

Available subcommands:
  create    Create a new group
  view      View a group
  list      List all groups
  filter    Filter groups
  members   Manage members of a group
  roles     Manage roles of a group

Usage:
  asg groups [flags]
  asg groups [command]

Aliases:
  groups, group

Examples:
asg groups list
asg groups --help

Available Commands:
  create      Create a new group
  delete      Delete a group
  filter      Filter groups
  members     Manage members of a group
  roles       Manage roles assigned to groups
  settings    Open group settings in browser
  update      Update a group
  view        View details of a specific group

Flags:
  -h, --help   help for groups

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output

Use "asg groups [command] --help" for more information about a command.
