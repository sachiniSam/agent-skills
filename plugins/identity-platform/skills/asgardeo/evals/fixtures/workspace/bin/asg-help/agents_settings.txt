Manage agents in your Asgardeo tenant. You can list, create, update, delete, and get details of agents.

Usage:
  asg agents [flags]
  asg agents [command]

Aliases:
  agents, agent

Examples:
asg agents

Available Commands:
  create      Create a new agent in your Asgardeo tenant
  delete      Delete an agent
  filter      Filter agents based on attributes
  update      Update an existing agent
  view        View details of a specific agent

Flags:
  -h, --help   help for agents

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output

Use "asg agents [command] --help" for more information about a command.
