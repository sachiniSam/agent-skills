Create a new API Resource in your organization

Usage:
  asg apis create [flags]

Examples:
asg apis create --name "Orders API" --description "Manage order operations" --identifier "https://api.example.com/orders" --require-auth --scopes '[{"name":"read:orders","description":"Read orders","displayName":"Read Orders"}]' -y
asg apis create --name "Billing API" --description "Billing workflows" --identifier "https://api.example.com/billing" --scopes "@scopes.json" -y
asg apis create --name "Inventory API" --description "Inventory operations" --identifier "https://api.example.com/inventory" -y
asg apis create --type mcp --name "Orders MCP" --identifier "http://localhost:3000/mcp" --require-auth --scopes '[{"name":"orders:read","displayName":"Read orders","description":"List orders"}]' -y
asg apis create

Flags:
      --description string   Description of the API resource
  -h, --help                 help for create
      --identifier string    Identifier of the API resource
  -n, --name string          Name of the API resource
      --require-auth         Require authorization for the API resource (provide the flag if true otherwise skip)
      --scopes string        Scopes of the API resource (provide as a valid JSON array or prefix with '@' to import from a file)
      --type string          Resource type: business (default), or mcp to register an MCP server. For mcp, use the MCP server URL as the identifier, since it becomes the token audience (default "business")
  -y, --yes                  Confirm the creation of the API Resource

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
