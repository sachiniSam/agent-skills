Filter API resources dynamically based on advanced query expressions such as 'name sw test' (starts with), 'name eq test' (equals), combined with limit constraints.

Usage:
  asg apis filter [flags]

Examples:
asg apis filter --query "name sw billing"
asg apis filter --query "name co 'api'" --count 5
asg apis filter --query "type eq BUSINESS" -N --format json
asg apis filter --query "type eq MCP"                 # the registered MCP servers

Flags:
  -c, --count string   Limit the number of results (default "10")
  -h, --help           help for filter
  -q, --query string   The expression used for filtering. Supported filters are 'Ew', 'Eq', 'Co', 'Sw', 'Ne' and 'and'. Filterable attributes: name, identifier, type. Example: 'name eq testapi', 'name sw test', or 'type eq BUSINESS' for the APIs you registered (as opposed to Asgardeo's built-in ones)

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
