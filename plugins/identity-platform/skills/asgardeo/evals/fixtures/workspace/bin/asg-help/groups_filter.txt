Filter groups in your organization using SCIM2 filter expressions.

Usage:
  asg groups filter [flags]

Examples:
asg groups filter --query "displayName eq testgroup"
asg groups filter --query "displayName eq testgroup" --count 5

Flags:
      --attributes string   Comma-separated list of attributes to return for each group
  -c, --count string        Maximum number of results to return (default "10")
  -h, --help                help for filter
  -q, --query string        SCIM2 filter query to filter groups
      --start string        Starting index for pagination

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
