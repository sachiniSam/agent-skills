Create a new user in the tenant
			A user can be created in the tenant by providing the user store, email, first name, last name and password.
			The user store is the identifier of the user store where the user will be created.
			The email is the username of the user.
			The first name and last name are the name of the user.
			The password is the password of the user's account.
			The password can be set on user creation or sent to the user to set the password.
			Password policies should be followed while setting the password.

			In non-interactive mode, the user store, email, first name, last name and password are required as flags
			In interactive mode, the attributes can be provided interactively or as flags

Usage:
  asg users create [flags]

Examples:
asg users create --user-store DEFAULT --email john.smith@example.com --first-name John --last-name Smith --password SecurePass123! --set-password -y
asg users create --email jane.doe@example.com --first-name Jane --last-name Doe --user-store DEFAULT -y

Flags:
      --email string        Email
      --first-name string   First name (Note: use -F)
  -h, --help                help for create
      --last-name string    Last name (Note: use -L)
      --password string     Password
      --set-password        Whether to set password for user on creation
      --user-store string   User store 
  -y, --yes                 Confirm creation

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
