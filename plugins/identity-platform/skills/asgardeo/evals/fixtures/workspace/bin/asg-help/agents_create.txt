Create a new agent in your Asgardeo tenant. This command allows you to create a new agent by providing the necessary details.

Usage:
  asg agents create [flags]

Examples:
asg agents create --name orders-assistant --description "Answers questions about orders" -y
asg agents create --name orders-assistant --allow-user-login --redirect-uri http://localhost:3001/callback -y
asg agents create --name nightly-approver --allow-user-login --agent-type background --redirect-uri http://localhost:3001/callback --notification-channels EMAIL -y
asg agents create --name orders-assistant --allow-user-login --redirect-uri http://localhost:3001/callback --env-file ./assistant/.env -y

Flags:
      --agent-type string               With --allow-user-login: interactive (users sign in through a browser redirect) or background (users approve out of band via CIBA; adds the CIBA grant) (default "interactive")
      --allow-user-login                Also create an OAuth application for the agent to sign in through (the Console's "Allow users to log in to this agent").
                                        The application shares the agent's ID; its client ID is printed with the result
      --ciba-expiry int                 With --agent-type background: seconds an approval request stays open (default 120)
  -c, --copy-password                   Copy the created agent's secret to clipboard without printing the secret on the terminal.
                                        If neither this nor --env-file is given the secret is printed on the terminal after the agent creation
      --description string              Description of the agent
      --env-file string                 Write the credentials into this dotenv file instead of showing the secret: AGENT_ID, AGENT_SECRET and (with --allow-user-login) CLIENT_ID.
                                        Existing lines for those keys are replaced, everything else is kept, and the file is created private (0600) if missing
  -h, --help                            help for create
  -n, --name string                     Name of the agent
      --notification-channels strings   With --agent-type background: how approval requests reach the user (EMAIL, SMS, EXTERNAL) (default [EMAIL])
      --redirect-uri string             With --allow-user-login: redirect URI registered on the agent's application (required)
  -y, --yes                             confirm the agent creation automatically

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
