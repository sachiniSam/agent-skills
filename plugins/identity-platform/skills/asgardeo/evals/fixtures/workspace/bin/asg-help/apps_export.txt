Write an application's configuration to a JSON file.

The exported file is the application's declarative representation. It differs from 'apps view' output, and is the format that 'apps update --file' accepts, so an application can be exported, edited and applied back.

Secrets are not exported: a client secret is left empty and is regenerated when the file is imported.

Usage:
  asg apps export [flags]

Examples:
asg apps export --id 7a4d5f50-cf2c-4de7-8b0f-b7f6f82c9ac4 --file app.json
asg apps export --name Orders --file app.json

Flags:
  -f, --file string    File to write the configuration to (JSON)
  -h, --help           help for export
  -i, --id string      Application ID
  -n, --name string    Application name prefix
  -q, --query string   Filter query to resolve the application

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
