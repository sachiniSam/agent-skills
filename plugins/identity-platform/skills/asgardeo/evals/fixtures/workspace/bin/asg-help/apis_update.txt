Update an API Resource by providing an ID or Name prefix.

Usage:
  asg apis update [flags]

Examples:
asg apis update --id 77e7ee21-da02-409e-bf8a-28f3bb186814 --new-name "Orders API v2" --description "Updated description" -y
asg apis update --id 77e7ee21-da02-409e-bf8a-28f3bb186814 --scopes "@scopes.json" -y
asg apis update --name orders --description "Updated description" -y
asg apis update --query "name sw orders" --new-name "Orders API" -y

Flags:
      --description string   Description of the API resource
  -h, --help                 help for update
  -i, --id string            ID of the API resource
  -n, --name string          Filter: name (prefix) of the API resource to update
      --new-name string      Complete Name of the API resource
  -q, --query string         Query to filter the API resource to update. (Example: --query "name sw test" or --query "name co 'web'")
      --scopes string        New scopes to add to the API resource (provide as a valid JSON array or prefix with '@' to import from a file)
  -y, --yes                  Confirm the update automatically

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
