View the complete details of a specific user by providing their ID or username prefix.
In interactive mode, if no ID is provided, you can select from a list of users.
You can use the -n flag to provide the prefix of the user name to search for the user and select the user from the list in the interactive mode.

Usage:
  asg users view [flags]

Examples:
asg users view --id 123e4567-e89b-12d3-a456-426614174000
asg users view --name john
asg users view --query "userName sw john"

Flags:
  -h, --help           help for view
  -i, --id string      User ID
  -n, --name string    User Name (prefix) to filter users
  -q, --query string   Query to filter the user to view. (Example: --query "username sw test" or --query "username co 'admin'")

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
