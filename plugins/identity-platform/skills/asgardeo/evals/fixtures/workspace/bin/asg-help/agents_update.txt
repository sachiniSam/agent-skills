Update an existing agent's attributes by providing an ID or Name.
You can either use granular flags (-a for add, -e for edit, -r for remove) to patch the agent,
You can use -r/-e/-a flags multiple times to update multiple fields.
or use an interactive file editor (-f) to modify the full JSON representation of the agent.

Interactive editing is not provided within the terminal. You can use the -f flag to export the agent to a file, edit it, and then import it back.
You can use the -n flag to provide the prefix of the agent name to search for the agent and select the agent from the list in the interactive mode.

Usage:
  asg agents update [flags]

Examples:
asg agents update --id 123e4567-e89b-12d3-a456-426614174000 --edit "urn:scim:wso2:agent:schema.DisplayName=New Name"
asg agents update --name AgentName --edit "urn:scim:wso2:agent:schema.Description=New Description" -y
asg agents update --id 123e4567-e89b-12d3-a456-426614174000 --file temp-agent.json

Flags:
  -a, --add strings      path (dot seperated) to add and value (= seperated) example: name=myagent
                          path.to.key=value
                          path.to.complex.json.value=@file.json
  -e, --edit strings     path (dot seperated) to edit and value (= seperated) example: name=newname
                          path.to.key=value
                          path.to.complex.json.value=@file.json
  -f, --file string      interactive: file to export the agent into, edit, and re-import; non-interactive (-N): prepared JSON file to import directly
  -h, --help             help for update
  -i, --id string        Agent ID
  -n, --name string      name (prefix) this will be used to search for agent
  -q, --query string     Query to filter the agent to update.
  -r, --remove strings   path (dot seperated) to remove
  -y, --yes              confirm update automatically

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
