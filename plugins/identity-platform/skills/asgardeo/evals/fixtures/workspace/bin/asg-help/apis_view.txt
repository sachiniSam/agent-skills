View an existing API resource from your organization
In interactive mode, you can select the API resource to view from the list of API resources
In non-interactive mode, you need to provide the API resource ID

The API resource details will be printed in the terminal in the configured format (json|yaml)

Usage:
  asg apis view [flags]

Examples:
asg apis view --id 77e7ee21-da02-409e-bf8a-28f3bb186814
asg apis view --name webhook
asg apis view --query "name sw billing"

Flags:
  -h, --help           help for view
  -i, --id string      ID of the API you want to view
  -n, --name string    Name (or prefix) of the API you want to view
  -q, --query string   Query to filter the API to view. (Example: --query "name sw test" or --query "name co 'web'")

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
