Manage your API resources in Asgardeo

Use this command to manage your API resources in Asgardeo

Available subcommands:
  create  Create a new API resource
  update  Update an existing API resource
  view    View an existing API resource
  delete  Delete an API resource
  list    List all API resources
  settings  Manage API resource settings in browser

Usage:
  asg apis [flags]
  asg apis [command]

Aliases:
  apis, api, api-resource, api-resources

Examples:
  asg apis list
  asg apis --help

Available Commands:
  create      Create a new API resource
  delete      Delete an existing API resource
  filter      Filter API resources
  scopes      Manage API scopes
  settings    Manage API resource settings in browser
  update      Update an existing API resource
  view        View an API resource

Flags:
  -h, --help   help for apis

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output

Use "asg apis [command] --help" for more information about a command.
