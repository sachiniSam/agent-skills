Update an existing application from your organization
In interactive mode, you can select the application to update from the list of applications
In non-interactive mode, you need to provide the application ID
You can also specify the fields to update using the --edit flag (dot separated paths, '=' separated values) example: 
name=newname
description=New description
advancedConfigurations.skipLoginConsent=true

if the value is a complex JSON struct you can provide it as a JSON file path using '@' prefix example: 
authenticationSequence=@sequence.json

--edit reaches fields of the application object itself. Protocol settings (callback URLs, access token type, grant types) live in a separate inbound-protocols resource: use 'asg apps protocol update'
You can also specify the file to update the application from using the --file flag (Only JSON is supported), 
You need to edit the file in an external text editor and confirm in the terminal to update the application

Usage:
  asg apps update [flags]

Examples:
asg apps update --id 7a4d5f50-cf2c-4de7-8b0f-b7f6f82c9ac4 --edit name=NewName
asg apps update --name web-portal --edit description='Updated app description' -y
asg apps update --query "name sw web" --edit name=NewName -y
asg apps update --id 7a4d5f50-cf2c-4de7-8b0f-b7f6f82c9ac4 --edit description='Updated app description' -y
asg apps update --id 7a4d5f50-cf2c-4de7-8b0f-b7f6f82c9ac4 --file app.json

Flags:
  -e, --edit strings   path (dot separated) to edit and value ('=' separated) example: name=newname
                        path.to.key=value
                        path.to.complex.json.value=@file.json
                        (application object fields only; protocol/OIDC settings are a separate resource — see the command help)
  -f, --file string    interactive: file to export the application into, edit, and re-import; non-interactive (-N): prepared JSON file to import directly
  -h, --help           help for update
  -i, --id string      Application ID
  -n, --name string    Application name prefix
  -q, --query string   Filter query to resolve the application
  -y, --yes            confirm the update automatically

Global Flags:
      --format string    output format (json|yaml)
      --no-color         Disable color output
  -N, --no-interactive   Disable interactivity
  -v, --verbose          Enable verbose output
